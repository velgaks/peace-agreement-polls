# Методологія та відтворення

[← До головної сторінки](../README.md)

## Метод

Підтримка переговорів, готовність до конкретної поступки, прогноз війни та підтримка референдуму є різними вимірами. Ряди різних організацій не склеєні.

Для 23 часових серій формулювання збережено в `data/wording.json` і `data/more-charts.json`. Ці файли містять питання, сценарій, опції, інструкції інтерв’юеру, джерело та відповідність опцій числовим рядам. Змінено лише пробіли й переноси рядків; слова, регістр, пунктуація та помилки видавця збережені. Суми опцій явно позначені. Легенда використовує версію останньої хвилі; паспорт, підказка точки та CSV — відповідної хвилі.

Розрізнено текст анкети, текст звіту, ретроспективний графік і довідкове формулювання іншої хвилі. Останні два випадки не підтверджують дослівність історичної анкети. Gallup наведено мовою англомовної публікації: українську анкету інтерв’ю не відтворено. Опрацьовані всі 138 записів каталогу. Для 135 збережено текст питання / судження та опції з анкети, звіту або ретроспективної таблиці; точний рівень підтвердження вказано для кожного запису. Для Q109–Q111 (PONARS/WDLS) повних питань і шкал у відкритих джерелах не знайдено: поля повного питання залишені порожніми, доступні фрагменти відокремлено. Англомовний текст та формулювання іншої хвилі не є підтвердженням української анкети конкретного заміру. Q137–Q138 — серпень 2025 у ретроспективному графіку NDI: повної шкали тут немає, підтверджені лише дві категорії неприйняття; це окрема хвиля від Q13–Q14 за березень 2026. Батареї тверджень і додаткові питання зберігаються окремо від шкал відповідей. CSV питань містить ці ж тексти та статуси.

Відсутня категорія не замінена нулем. Точки з’єднані лініями, зокрема через зміни методики; пропуски значень залишаються розривами. Методологічні зміни описані у примітках під графіками та у SVG-експорті. Для IRI зазначено зміну географії зважування у 2026 році. Для SOCIS — зміну згадки про Мінські угоди, невстановлену точну межу цієї зміни та вибірку 16+ у березні 2025. Для Разумкова — появу нових варіантів відповідей. Лінії не означають повної зіставності хвиль. Дві січневі хвилі КМІС 2026 року збережені окремо. У NDI використані авторські агрегати 70%, а не суми округлених сегментів 69%.

Вісь часу використовує поле `sort`: точний день, якщо він заданий; середину місяця або року, якщо ключ менш точний. Це позиціонування точки, а не встановлення невідомої дати поля. У таблицях подано окремі дати поля, коли вони доступні. Підвибірка конкретного питання може бути меншою за загальне n хвилі.

КМІС, Разумков, ФДІ, «Рейтинг», Info Sapiens, Gallup, NDI, IRI та інші проєкти представлені з виконавцями, замовниками, методами і межами охоплення. Онлайн-панелі мають нижчий пріоритет. Неопубліковані дослідження не охоплено. Докладний журнал охоплення міститься у розділі «Метод» і полі `coverage`.

## Дані й відтворення

`data/research.json` є публічним знімком числового реєстру; його короткі назви відповідей слугують внутрішніми ключами. `data/wording.json` містить тексти першоджерел, а `wording.js` зіставляє їх із рядами. `series.js` містить редакційні назви й методологічні примітки. `data/more-charts.json` містить 153 панелі для 138 записів, додаткові формулювання й метадані 11 нових часових серій; `question-charts.js` відображає графіки окремих питань. Часткові розподіли позначені, відсутні відповіді не добудовано до 100%. Середні бали показані на вихідних шкалах 1–5 або 1–10. Для експерименту КМІС наведено оцінки 13 рівнів параметрів, а не 96 малих експериментальних груп. `lib.js` зберігає пропуски під час побудови графіків. Вихідні PDF/HTML залишаються у видавців; у цьому репозиторії опубліковано числа, формулювання й посилання.

Оновлення з вихідного реєстру:

```sh
python scripts/structure_wording.py /path/to/peace-agreement-polls-archive
python scripts/export_data.py /path/to/research-data.json
python scripts/build_more_charts.py /path/to/peace-agreement-polls-archive
python scripts/build_previews.py
node --test
```

Для повторного видобування даних із локального архіву джерел скрипту `build_more_charts.py` потрібні PyMuPDF та BeautifulSoup. Згенеровані JSON/JS уже включені до репозиторію.

Локальний запуск без встановлення залежностей:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Відкрити `http://127.0.0.1:8765`. Для перевірок потрібен Node.js 22 або новіший. Статичний сайт публікується GitHub Pages із кореня гілки `main`; збірка не потрібна. Шрифти Literata і Source Sans 3 завантажуються через Google Fonts; за їх відсутності використовується резервний шрифт. Трекерів і бекенду немає.

## Джерела та атрибуція

Усі 140 посилань містяться в `data/research.json` (`sources`); CSV містять поле `source_url`. Авторські права на оригінальні звіти залишаються у відповідних організацій.

Упорядкування та графіки: Valentyn Hatsko, [@gorbach_squad](https://t.me/gorbach_squad). Проєкт розвиває підхід [promarket-attitudes](https://github.com/velgaks/promarket-attitudes).

Помилку у цифрі, джерелі чи формулюванні можна описати в [Issues](https://github.com/velgaks/peace-agreement-polls/issues), вказавши ID запису, сторінку та виправлення.

Питання, сценарій та параметри експерименту зберігаються окремо. Для Q05 сценарій витягнуто з конкретної клітинки анкети; для Q25 — п’ять вимірів і 13 рівнів із матриці. Поля `prompt_items` і `experiment_dimensions` зберігають структуру списків у JSON та CSV.
