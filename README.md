# Опитування про переговори та мирні ініціативи

Добірка опитувань українців про підтримку переговорів, мирні ініціативи, прийнятні умови та поступки від 2022 року. **[Відкрити дешборд](https://velgaks.github.io/peace-agreement-polls/)**.

MVP містить 12 часових серій, 117 записів про хвилі, агрегати та ретроспективні точки, 138 розібраних питань, 346 числових значень динаміки і 94 значення з перехресних таблиць. Дані зібрані станом на 5 жовтня 2026 року. Це кількість записів, а не незалежних вибірок.

## Можливості

- Часові ряди з першоджерелами, паспортами та примітками про зіставність.
- Каталог і питання з пошуком та фільтрами. Основні джерела відділені від додаткових і недостатньо перевірених.
- Опубліковані перетини зі знаменниками підгруп.
- Шість робочих позицій з підставами й межами висновків. Їхні індикатори не складаються до 100%.
- Завантаження даних CSV/JSON, окремого графіка SVG і посилання на обрану серію.

## Метод

Підтримка переговорів, готовність до конкретної поступки, прогноз війни та підтримка референдуму є різними вимірами. Ряди різних організацій не склеєні. Перекази формулювань позначені; оригінальні анкети доступні за посиланнями.

Відсутня категорія не замінена нулем. Точки з’єднані лініями, зокрема через зміни методики; пропуски значень залишаються розривами. Методологічні зміни описані у примітках під графіками та у SVG-експорті. Для IRI зазначено зміну географії зважування у 2026 році. Для SOCIS — зміну згадки про Мінські угоди, невстановлену точну межу цієї зміни та вибірку 16+ у березні 2025. Для Разумкова — появу нових варіантів відповідей. Лінії не означають повної зіставності хвиль. Дві січневі хвилі КМІС 2026 року збережені окремо. У NDI використані авторські агрегати 70%, а не суми округлених сегментів 69%.

Вісь часу використовує поле `sort`: точний день, якщо він заданий; середину місяця або року, якщо ключ менш точний. Це позиціонування точки, а не встановлення невідомої дати поля. У таблицях подано окремі дати поля, коли вони доступні. Підвибірка конкретного питання може бути меншою за загальне n хвилі.

КМІС, Разумков, ФДІ, «Рейтинг», Info Sapiens, Gallup, NDI, IRI та інші проєкти представлені з виконавцями, замовниками, методами і межами охоплення. Онлайн-панелі мають нижчий пріоритет. Неопубліковані дослідження не охоплено. Докладний журнал охоплення міститься у розділі «Метод» і полі `coverage`.

## Дані й відтворення

`data/research.json` є публічним знімком реєстру. `series.js` містить редакційні назви, методологічні примітки. `lib.js` зберігає пропуски під час побудови графіків. Вихідні PDF/HTML залишаються у видавців; у цьому репозиторії опубліковано числа й посилання.

Оновлення з вихідного реєстру:

```sh
python scripts/export_data.py /path/to/research-data.json
node --test
```

Локальний запуск без встановлення залежностей:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Відкрити `http://127.0.0.1:8765`. Для перевірок потрібен Node.js 22 або новіший. Статичний сайт публікується GitHub Pages із кореня гілки `main`; збірка не потрібна. Шрифти Literata і Source Sans 3 завантажуються через Google Fonts; за їх відсутності використовується резервний шрифт. Трекерів і бекенду немає.

## Джерела та атрибуція

Усі 140 посилань містяться в `data/research.json` (`sources`); CSV містять поле `source_url`. Авторські права на оригінальні звіти залишаються у відповідних організацій.
