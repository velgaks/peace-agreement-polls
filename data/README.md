# Як читати таблиці

**[questions.csv](questions.csv)** — каталог 138 питань, тверджень, сценаріїв і батарей із конкретних опитувань. Це не 138 незалежних вибірок: `poll` посилається на паспорт хвилі у [polls.csv](polls.csv). Окремі записи об’єднують кілька пов’язаних тверджень або умов експерименту.

Першими після ID стоять тексти з джерел:

| Колонка | Що містить |
|---|---|
| `wording_question` | Формулювання питання або твердження |
| `wording_prompt` | Сценарій / умови, які зачитували разом із питанням |
| `wording_options` | Опубліковані варіанти відповідей, як JSON-масив |
| `wording_source_url` | Джерело формулювання |
| `wording_basis` | Підстава відтворення: анкета, звіт, ретроспектива тощо |

`scenario_summary` та `result_summary` — редакційні перекази, не цитати з анкети. `wording_prompt_items`, `wording_statements`, `wording_followups` та `wording_experiment_dimensions` зберігають окремі пункти списків, батарей, додаткових питань і експериментів. `wording_note` пояснює межі відтворення. Ретроспективний графік не підтверджує дослівність історичної анкети.

У 135 записах заповнено `wording_question`. Для Q109–Q111 (PONARS / WDLS) повні питання й шкали у відкритих матеріалах не знайдені: поле порожнє, доступний фрагмент збережено окремо. Порожній JSON-масив `[]` не означає, що респондентам не давали варіантів відповіді.

**[polls.csv](polls.csv)** — паспорти хвиль, ретроспективних точок та агрегатів: організація, дати, вибірка, метод, джерела й обмеження. **[dynamics.csv](dynamics.csv)** — числові спостереження часових серій. **[crosses.csv](crosses.csv)** — опубліковані перехресні розподіли.

Докладніше: [методологія](../docs/METHODOLOGY.md). Для читання без горизонтального прокручування CSV — [розділ «Усі питання» на сайті](https://velgaks.github.io/peace-agreement-polls/#conditions).
